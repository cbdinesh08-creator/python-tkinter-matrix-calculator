Python Tkinter Matrix Calculator

Project Description

The Python Tkinter Matrix Calculator is a graphical user interface (GUI) application developed using Python. It performs various matrix operations with a simple and user-friendly interface.

Objectives

- To perform matrix calculations easily.
- To develop a user-friendly graphical interface.
- To understand the implementation of matrix operations using Python.

Features

1. Matrix Multiplication
2. Matrix Square
3. Determinant Calculation
4. Matrix Adjoint
5. Matrix Inverse

Technologies Used

- Programming Language: Python
- GUI Library: Tkinter
- Development Environment: VS Code / Python IDLE

How to Run the Project

1. Install Python on your computer.

2. Download the "matrix_calculator.py" file.

3. Open the terminal in the downloaded file's folder.

4. Run the following command:
   
   "python matrix_calculator.py"

Project Files

- "matrix_calculator.py" – Contains the complete Python source code.
- "README.md" – Contains the project description and instructions.

Conclusion

This project provides a simple way to perform basic matrix operations through a graphical interface using Python and Tkinter.
